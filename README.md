# 🩺 Breast Cancer Classification using Machine Learning

## 📌 Project Overview

This project predicts whether a breast tumor is **Benign** or **Malignant** using Machine Learning algorithms. Early detection of breast cancer plays a crucial role in improving treatment outcomes and saving lives.

The model is trained on the Breast Cancer Wisconsin Dataset and performs binary classification based on various medical features extracted from tumor cell images.

---

## 🎯 Objective

- Predict breast cancer diagnosis.
- Compare the performance of different Machine Learning models.
- Evaluate models using standard classification metrics.
- Build a reliable classification system for early diagnosis.

---

## 📂 Dataset

- **Dataset:** Breast Cancer Wisconsin Diagnostic Dataset
- **Source:** Scikit-learn (`load_breast_cancer()`)

### Features

The dataset contains **30 numerical features**, including:

- Mean Radius
- Mean Texture
- Mean Perimeter
- Mean Area
- Mean Smoothness
- Mean Compactness
- Mean Concavity
- Mean Symmetry
- Fractal Dimension
- and many more...

### Target Classes

| Value | Diagnosis |
|--------|-----------|
| 0 | Malignant |
| 1 | Benign |
